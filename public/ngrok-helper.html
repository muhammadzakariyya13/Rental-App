🚀 Ngrok URL Helper untuk Webhook

📋 Langkah Setup Ngrok

1
Download Ngrok: https://ngrok.com/download
2
Extract ke: C:\ngrok\
3
Daftar gratis: ngrok.com untuk dapat authtoken

💻 Commands untuk Menjalankan

cd C:\ngrok
ngrok config add-authtoken YOUR_AUTHTOKEN_FROM_DASHBOARD
cd "D:\PROJEK LARAVEL\Rental-App"
/c/laragon/bin/php/php-8.2.28-Win32-vs16-x64/php.exe artisan serve
cd C:\ngrok
ngrok http 8000

🔗 Generate Webhook URL

Copy URL HTTPS dari terminal ngrok yang dimulai dengan https://...ngrok-free.app

✅ URL untuk Payment Gateway Dashboard:

Paste URL ini ke field "Webhook URL" di payment gateway dashboard
